# Migration-to-Australia-Vega-Lite
Interactive data visualisation exploring 20 years of Australian migration trends using Vega-Lite, including migration flows, source countries, state settlement patterns, and visa categories.

### Overview
This project analyses Australia's Net Overseas Migration from 2004–05 to 2024–25 through a narrative-driven dashboard built with Vega-Lite. The visualisation explores where migrants came from, where they settled, and which visa categories contributed most to migration patterns over time.

### Features
- Interactive Vega-Lite visualisations
- Choropleth maps and heatmaps
- Migration trends by country and region
- State-level settlement analysis
- Visa category migration breakdowns
- Data storytelling with annotations and insights

### Technologies
- Vega-Lite
- JavaScript
- HTML
- CSS
- GitHub Pages
